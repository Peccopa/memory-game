# Vercel

## Что такое Vercel

**Vercel** — платформа для сборки и публикации frontend-приложений.

Проект можно подключить к GitHub, после чего Vercel автоматически собирает и разворачивает приложение при изменениях в репозитории.

Для нашего starter pack Vercel является **внешним инструментом**, а не частью проекта:

- не устанавливается через npm;
- не требует добавления зависимостей;
- не требует `vercel.json` для обычного Vite-проекта;
- не влияет на структуру исходного кода.

---

## Production и Preview

После подключения GitHub используется простая схема:

```text
main
  │
  └── push
       ↓
   Production
       ↓
   live site
```

Изменения в других ветках могут создавать отдельные Preview Deployments:

```text
feature/123-new-feature
          │
          └── push
                ↓
             Preview
                ↓
          preview URL
```

Preview позволяет проверить изменения до попадания в `main`. При работе через Pull Request Vercel может автоматически создать preview и добавить ссылку на него в PR.

---

## Подключение проекта

1. Войти в Vercel через GitHub.
2. Выбрать **Add New → Project**.
3. Импортировать GitHub-репозиторий.
4. Проверить настройки сборки.
5. Нажать **Deploy**.

Vercel автоматически определяет используемый frontend-инструмент и предлагает подходящие настройки сборки.

Для нашего Vite-проекта используются:

```text
Build Command:
npm run build

Output Directory:
dist
```

## Нужно ли добавлять Vercel в starter?

**Нет.**

Vercel не является частью самого starter pack.

В проект не добавляем:

```text
vercel.json
```

и не устанавливаем никаких Vercel-пакетов только ради обычного deployment.

Подключение Vercel выполняется уже после создания конкретного проекта.

Поэтому starter остаётся независимым от конкретной платформы деплоя.

---

## Когда Vercel особенно полезен

Vercel имеет смысл использовать для:

- frontend-проектов;
- SPA;
- статических сайтов;
- демонстрации учебных проектов;
- проверки Pull Request через Preview Deployment;
- быстрого получения публичного URL.

Для учебных и портфолио-проектов особенно полезна возможность показать работающую версию приложения до merge в `main`.
