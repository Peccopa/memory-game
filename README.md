# Memory Game

Браузерная игра на запоминание пар карт, разработанная в рамках курса Rolling Scopes School.

## Описание

Memory Game — классическая игра на поиск одинаковых пар карт.

Игровое поле содержит:

- 16 карт;
- 8 пар;
- случайную раскладку карт при каждом запуске новой игры.

Цель игры — открыть все пары карт, сделав как можно меньше ходов.

## Возможности

- случайное перемешивание карт;
- открытие карт и поиск совпадающих пар;
- автоматическая проверка совпадений;
- задержка перед закрытием несовпавших карт;
- блокировка игрового поля во время проверки несовпадения;
- счётчик ходов;
- счётчик найденных пар;
- автоматическое определение победы;
- модальное окно с результатом игры;
- запуск новой игры в любой момент;
- таблица лидеров;
- сохранение результатов в `localStorage`;
- хранение до 10 лучших результатов;
- сортировка результатов по количеству ходов и времени завершения игры;
- закрытие модальных окон кнопкой, кликом по фону и клавишей `Escape`;
- блокировка прокрутки страницы при открытом модальном окне;
- адаптивная вёрстка;
- визуальное оформление в стиле игральных карт и казино.

## Подсказка для проверки игры

Для удобства разработки и проверки победы в консоль выводится расположение карт в виде сетки 4×4.

Пример:

```text
🃏 Card hint:
[A♠] [K♥] [Q♦] [J♣]
[10♠] [9♥] [8♦] [7♣]
[A♠] [K♥] [Q♦] [J♣]
[10♠] [9♥] [8♦] [7♣]
```

Подсказка позволяет быстро найти все пары и проверить логику завершения игры.

Это отладочный инструмент и не является частью основного игрового интерфейса.

## Управление

1. Нажмите на любую закрытую карту.
2. Откройте вторую карту.
3. Если карты совпадают, они остаются открытыми.
4. Если карты не совпадают, через короткую задержку они закрываются.
5. Во время проверки несовпадения другие карты недоступны.
6. Продолжайте игру, пока не будут найдены все 8 пар.

Один ход состоит из открытия двух разных карт.

## Таблица лидеров

После победы результат автоматически сохраняется в `localStorage`.

В таблице отображаются:

- место;
- количество ходов;
- дата завершения игры.

В таблице сохраняются максимум 10 результатов.

Результаты сортируются:

1. сначала по количеству ходов — от меньшего к большему;
2. при одинаковом количестве ходов — по времени завершения игры.

Незавершённые игры в таблицу лидеров не попадают.

## Новая игра

Кнопка `New Game` позволяет начать новую игру в любой момент.

При запуске новой игры:

- создаётся новая колода;
- карты перемешиваются;
- счётчики сбрасываются;
- состояние текущей игры очищается;
- предыдущие результаты таблицы лидеров сохраняются.

## Модальные окна

В игре используются два модальных окна.

### Окно победы

Появляется автоматически после нахождения всех 8 пар.

Содержит:

- сообщение о победе;
- количество сделанных ходов;
- кнопку новой игры;
- кнопку закрытия.

### Таблица лидеров

Открывается из шапки игры.

Открытие таблицы лидеров не сбрасывает текущую игру.

### Основные сущности

**Card**

Отвечает за данные и отображение игровых карт.

**Game**

Содержит состояние игры, действия и reducer игровой логики.

Отвечает за сохранение, получение и сортировку результатов.

**Widgets**

Содержат основные визуальные части игрового интерфейса.
